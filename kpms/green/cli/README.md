# Host CLI

`green.py` speaks the small TCP control protocol to the root `green` daemon.
The daemon injects `green_hook/agent`, provisions the KPM token, and forwards
only script/control messages. Memory writes are performed by the injected
Frida GumJS memory backend through authenticated KPM shadow requests.

```sh
adb forward tcp:27042 tcp:27042
python3 cli/green.py ps
python3 cli/green.py attach -f com.example.app -l test/example_hook.js
python3 cli/green.py eval -p PID -c "Process.enumerateModules()"
```

The CLI never supplies a token in the wire protocol. Tokens are generated by
the root daemon, registered with KPM, and sent to the agent over its root-only
Unix control socket. This prevents a host client or untrusted app process from
reusing another process' authorization.
